Student Performance Prediction

Overview:
A machine learning project exploring the prediction
of student academic performance using relevant features.

Objectives:
- Explore and preprocess a dataset.
- Train a baseline regression model.
- Evaluate performance using appropriate metrics.
- Document the model's limitations.

Tech Stack:
- Python
- Pandas
- Scikit-learn
- Matplotlib

Project Status:
Initial setup in progress.

Limitations:
Predictions are experimental and should not be used
to make high-stakes decisions about students.
